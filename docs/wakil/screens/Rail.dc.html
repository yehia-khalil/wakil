What changes
State 1 was what shipped, and it was interactive in that state — a click focused the pane. §3 says far-plane content is never interactive without first being promoted, and §10 says the rail is “low opacity until relevant.” Nothing ever made it relevant. State 3 is that missing promotion, built 2026-09-21: scale, opacity and blur released together — never one alone — over §7’s 400–600ms ease-out, with hover as what makes the rail relevant. One thing this sheet does not draw, settled in the code: promotion outranks state 4’s fade, because while a pane is maximized the rail is the only way back to the others.
State 2 is §10’s other unkept promise, kept on the same date. A working pane is meant to glow green in the periphery; the code draws the literal word “working” in cool white. Green on the tick is legible from the corner of the eye at far-plane opacity, which is the whole point of putting it there — and it is the one luminous mark §8 already permits.
State 1 composites to 2.35:1 against the void — the same class of failure EnvironmentBadge was created to fix at 1.47:1. Pane names are read, so the 4.5:1 floor applies. Promotion is what clears it, at the moment it is read: 16.9:1 for a name, 5.4:1 for the kind beside it. Pinned 2026-09-21 in RailTreatmentTests, on EnvironmentBadgeTests’ pattern — both that the promoted state clears the floor and that the ambient one would fail it. Building it found one more: the kind column drawn at 0.46 composites to 4.09:1 even promoted, so it ships at 0.55 and this sheet was corrected to match.
