The context line does not carry reachability, and must not. An environment is a fact about project.json; whether one of its three databases answers right now is a fact about that database. Marking the segment would make one dead resource look like a failed switch — the switch succeeded. The pane that tried to read names which one, and says so in the shape unreadProviders already uses: answered-and-had-nothing stays distinguishable from was-never-asked.
