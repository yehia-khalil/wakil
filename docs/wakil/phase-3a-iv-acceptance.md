# 3a-iv — branches and stash: acceptance

**Spec:** [`2026-10-23-3a-iv-branches-and-stash-design.md`](../superpowers/specs/2026-10-23-3a-iv-branches-and-stash-design.md)
· **Charter:** Invariant 6 (the eighth write), Decision 46

The exit criterion, from the spec: the operator switches, creates, renames and deletes branches, and
stashes, applies, pops and drops stashes, from the context line's Branch segment and the Changes
view, as VS Code does; changes in the way are stashed or brought along, never lost; the agent and
voice reach the same actions, and delete and drop ask the operator when they ask.

Nothing here is walked yet: the Walked column is empty until the operator ticks it.

## 0. Setup

Run this in the worktree root, on this Mac, after `make build` and `make app-bundle`. It is safe to
re-run.

```bash
(
set -e
REPO="$(git rev-parse --show-toplevel)"
ORG=personal
W="$TMPDIR/walk-3a-iv"
rm -rf "$W"
mkdir -p "$W/project"
export GIT_CONFIG_GLOBAL=/dev/null GIT_CONFIG_SYSTEM=/dev/null
g() { git -c user.name=seed -c user.email=seed@example.com "$@"; }
git init -q --bare -b main "$W/remote.git"
git clone -q "$W/remote.git" "$W/work"
cd "$W/work"
printf 'one\ntwo\nthree\n' > a.txt
git add . && g commit -qm seed && git push -q -u origin main
g switch -q -c feature/search && echo search > s.txt && git add s.txt && g commit -qm search
git switch -q main
g switch -q -c other && printf 'one\nOTHER\nthree\n' > a.txt && g commit -qam other && git push -q origin other
git switch -q main && git branch -q -D other && git fetch -q origin
cat > "$W/project/project.json" <<J
{"name":"walk-3a-iv","org":"$ORG","roots":[{"path":"$W/work"}],"scopes":{},"environments":{}}
J
cd "$REPO"
./bin/wakil project rm walk-3a-iv --org "$ORG" || true
./bin/wakil project add walk-3a-iv --path "$W/project/project.json" --org "$ORG"
)
```

`work` is on `main`, with a local `feature/search` one commit ahead and a remote-only `origin/other`
whose `a.txt` differs. Launch from the worktree root with
`WAKIL_ORG=personal WAKIL_GIT_ALLOW_FILE=1 app/Wakil.app/Contents/MacOS/Wakil`, make `walk-3a-iv`
active with ⌘P, open an editor pane and press ⌘⇧G. Terminal commands run from any folder.

## 2. Known and not fixed

- Merge, rebase and resolving a clash are 3a-v's; a clash here keeps the stash and leaves the files as
  the branch has them.
- Tags, a detached checkout and deleting a remote branch are not in this phase.

## 3. Residue: what the walk cannot establish

- Bring Them Along cancelled between its steps (it says where the changes are) is pinned by
  `TestCancelBetweenStashAndPopSaysWhere`; the walk's git is too fast to catch between steps.
- A stash list moved by another worktree between reading and dropping is pinned by
  `TestAMovedStashListIsRefused`.
