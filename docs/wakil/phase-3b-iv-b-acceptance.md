# 3b-iv-b — file icons by language: acceptance

**Spec:** [`2026-10-18-3b-iv-b-file-icons-design.md`](../superpowers/specs/2026-10-18-3b-iv-b-file-icons-design.md)

The exit criterion, from the spec: file rows in the Files tree, rows in the Changes view and
editor tabs show a single-colour Seti glyph for the file's language, in the name's own colour;
folders, Search results and ⌘P show none.

## 0. Setup

Run this in the repo root, on this Mac, after `make build` and `make app-bundle`. It is safe to
re-run.

```bash
(
set -e
ORG=personal
cd ~/Desktop/scripts/wakil-public-3b-iv-b
W="$TMPDIR/walk-icons"
rm -rf "$W"
export GIT_CONFIG_GLOBAL=/dev/null GIT_CONFIG_SYSTEM=/dev/null
g() { git -c user.name=walk -c user.email=walk@example.com "$@"; }
mkdir -p "$W/api/cmd" "$W/api/web" "$W/api/build" "$W/project"
cd "$W/api" && git init -q -b main
echo 'package main' > cmd/main.go
echo '<?php' > web/index.php
echo 'export const a = 1' > web/app.ts
echo '{}' > package.json
echo 'a: 1' > ci.yml
echo 'select 1;' > q.sql
echo '# api' > README.md
echo 'FROM alpine' > Dockerfile
echo 'all:' > Makefile
echo 'build/' > .gitignore
echo 'x' > build/out.js
g add . && g commit -qm init
echo '// changed' >> cmd/main.go
echo 'new' > notes.md
cat > "$W/project/project.json" <<J
{"name":"walk-icons","org":"$ORG","roots":[{"path":"$W/api"}],"scopes":{},"environments":{}}
J
cd ~/Desktop/scripts/wakil-public-3b-iv-b
./bin/wakil project rm walk-icons --org "$ORG" || true
./bin/wakil project add walk-icons --path "$W/project/project.json" --org "$ORG"
)
```
