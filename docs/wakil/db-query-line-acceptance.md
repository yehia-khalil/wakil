## 2. Residue: what no check covers, and why

- **Wrapping and the six-line cap** (walk 1): no step kind reads geometry.
- **Brightness, no hue** (walk 2): a visual ruling.
- **⌘Z after Format** (walk 4): the journal is append-only and the tree flattens newlines,
  so no step can tell the restored layout apart.
- **⇧Return runs nothing** (walk 7): a journal step can only assert that text is present,
  not that something is absent.
- **The caret stays on its token** (walk 8): no step kind reads the selection.
- **A sort keeps unsaved edits** (walk 6): on the two-row fixture a sort never changes the
  line, so a check could not fail.
- **Mongo pretty-print**: the fixture has no Mongo database. `SQLFormatTests` covers it.
- **The "not formatted" line** is display text, so nothing can press it. It is listed in
  `uncoverable.tsv` and asserted by `db-query-line-not-formatted.jsonl`.
