# 3c-i: the browser — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `browser` pane kind: WebKit tabs inside one pane, an address field, navigation, a profile per
organisation, find, zoom, downloads, in-place prompts, Web Inspector, layout save/restore, Settings → Browser.

**Architecture:** WakilKit gets a `Browser/` folder (kind, store methods, actions, the address rule, the
org's profile and files); the pane's state lives in `PaneStore` like every kind. WakilApp owns the
`WKWebView`s in a `BrowserTabHost` and reports what the page does back through one seam
(`WindowModel.browserPageDidReport…`), the editor renderer's pattern. Actions drive the web view by
writing a sequenced *command* into the tab, which the host applies once.

**Tech Stack:** Swift 6 / SwiftUI / AppKit, WebKit (`WKWebView`, `WKWebsiteDataStore(forIdentifier:)`,
`WKDownload`, `interactionState`), Swift Testing; Go (`wakil-ctx`) for the app-wide setting; the e2e driver (Go).

**Spec:** `docs/superpowers/specs/2026-10-25-3c-browser-design.md` — calls 1–5, 7 (environment band only),
8, 9, 12 (3c-i), 13. 3c-ii (agent page read/act, tab tags) and 3c-iii (history, bookmarks, links) are not
in this plan.

## Global Constraints

- Platform floor `macOS 14.4` (`app/Package.swift`); no new Swift package dependency.
- Pane kind name `"browser"`; default title `"Browser"`; palette row `"New Browser pane"`.
- Org files under `~/.wakil/orgs/<org>/browser/`: `profile.json` (`{"identifier":"<UUID>"}`),
  `zoom.json` (`{"<host>": <factor>}`), `tabs/<tab-id>.state` (WebKit `interactionState`, binary).
- Search engines and their query URLs: `google` `https://www.google.com/search?q=`, `duckduckgo`
  `https://duckduckgo.com/?q=`, `bing` `https://www.bing.com/search?q=`, `kagi` `https://kagi.com/search?q=`.
  Default `google`. Start page default `""` (blank).
- Zoom steps: `0.5, 0.67, 0.8, 0.9, 1.0, 1.1, 1.25, 1.5, 1.75, 2.0, 2.5, 3.0`; reset `1.0`.
- At most **20** live web views per window; older tabs keep their URL and are rebuilt on selection.
- Keys while a browser pane is focused: ⌘T new tab, ⌘W close tab (last tab closes the pane), ⌘⇧T reopen,
  ⌘L address, ⌘R reload, ⌘[ / ⌘] back/forward, ⌘F find, ⌘G / ⌘⇧G next/previous, ⌘+ / ⌘− / ⌘0 zoom,
  ⌃Tab / ⌃⇧Tab and ⌘⇧] / ⌘⇧[ next/previous tab, ⌘1–8 tab N, ⌘9 last tab. Elsewhere every key keeps today's meaning.
- Keys always Wakil's even when the page has focus: ⌘K, ⌘P, ⌘N, ⌘T, ⌘W, ⌘L, ⌘1–9, ⌘, and ⌘⇧W.
- Copy, verbatim: load error `Couldn't reach <host> — <localizedDescription> (<NSURLError code name>)`
  with **Try Again**; crashed page `This page stopped.` with **Reload**; certificate `<host>'s certificate
  isn't trusted — <reason>` with **Visit Anyway** (operator only, for the session); media prompt
  `<host> wants to use your camera` / `microphone` / `camera and microphone` with **Allow** / **Don't Allow**;
  clear data confirm `Delete <org>'s browsing data? Every site signs you out, in every project.` with
  **Keep it** / **Delete**.
- Info.plist: add `NSCameraUsageDescription` = `A web page in Wakil's browser asked to use the camera.`;
  `NSMicrophoneUsageDescription` becomes `Wakil listens while you hold ⌥, and when a web page in its browser asks and you allow it. Audio for speech never leaves this Mac.`;
  add `NSAppTransportSecurity` → `NSAllowsArbitraryLoadsInWebContent` = true (plain-http pages; ATS still
  guards Wakil's own requests).
- No `Co-Authored-By` / "Generated with" lines in commits.

## Review Focus

1. **Typed addresses that look like words.** `localhost:3000`, `10.0.0.5:8080/x`, `foo.test`,
   `api.initech.dev/docs`, `[::1]:8080` must load, `confirm booking 409` and `swift.org is great` must search.
   Pinned in Task 2's table.
2. **⌘T and ⌘W outside a browser.** An editor-focused ⌘T still opens a scratch tab; ⌘W in an editor still
   closes its tab. Pinned in Task 5's `keysOutsideABrowserKeepTodaysMeaning`.
3. **A restored pane with many tabs.** Only the active tab loads; the rest stay unloaded until selected.
   Pinned in Task 4's `restoreLoadsOnlyTheActiveTab`.
4. **Reports for a tab that has gone.** A navigation callback after ⌘W (a slow page finishing) must not
   resurrect the tab or move the active one. Pinned in Task 4's `aReportForAClosedTabIsDropped`.
5. **One org's cookies in another org.** The profile identifier differs per org and a web view is never
   reused across orgs. Pinned in Task 6's `eachOrgHasItsOwnIdentifier` and Task 7's host key `(org, pane, tab)`.
