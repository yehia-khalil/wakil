# Names Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Conversations are named once by the organisation's quick model and renamed by the operator or the agent anywhere they are listed; browser tabs can be renamed, the name kept and saved with the tab.

**Architecture:** A conversation's title becomes derived from three slots on `PlaceAgent` (operator name, model name, first-message title). The model name comes from a `QuickTasks.respond` caller (`ConversationNames`, prompt + parser), the operator name only from the new `conversation_rename` action, parked on `ConversationBroker`. Names persist per lineage root in `~/.wakil/orgs/<org>/conversation-names.json` (Swift). The palette gains one "name step" used by every palette rename. The browser half adds `BrowserTab.name`, `browser_rename_tab`, and carries the name through the layout, the closed list and pins.

**Tech Stack:** Swift 6 (WakilKit, Swift Testing), SwiftUI/AppKit (WakilApp), Go (`internal/wakilcore`, `cmd/wakil-ctx`), the e2e harness (`e2e/`).

**Spec:** `docs/superpowers/specs/2026-10-28-names-design.md`

## Global Constraints

- Tasks 1–11 build on `main`. **Tasks 12–16 need 3d-i merged into `main` first** (`BrowserTab.group/pin`, `BrowserSavedTab.pin`, `BrowserPin`, `BrowserTabMenu`, `BrowserTabColumn`, `BrowserGroupNames`); start them only after `git log main` shows 3d-i's merge.
- Display rule: `title = operatorName ?? aiName ?? messageTitle`; `messageTitle` is today's `conversationTitle(firstMessage)` / `"New conversation"`.
- Model name: at most five words, then the first whole words fitting 48 characters.
- Sent: `MESSAGE:` first typed message cut to 1,000 characters, blank line, `REPLY:` first turn's assistant text cut to 600 characters; `maxTokens: 24`. Instructions copy, verbatim: `Name this conversation from its opening message and the start of the reply. Answer with at most five words, no quotes, as JSON: {"name": "..."}.`
- File: `~/.wakil/orgs/<org>/conversation-names.json`, `{"<lineageRoot>": {"operator": "...", "ai": "..."}}`.
- Setting key `conversationNames` (org.json, nil = on); row label **Name conversations with AI**, hint *Names a conversation from its first message and reply*; identifiers `settings.org.conversationNames.on` / `.off`.
- Actions: `conversation_rename {conversation?, name}` and `browser_rename_tab {pane?, tab?, name}`, both `.control`, `.agentReachable`. Empty `name` clears.
- Refusal copy: `conversation_rename: an agent renames only its own conversation (conversations call 5: an agent does not know about the others)`; `conversation_rename: no live conversation <id>`.
- Status copy: `conversation names: could not save <path>: <error> — the name holds until Wakil quits`; `conversation names: <path> is unreadable: <error>`.
- Palette copy: `Rename Conversation…`, `Rename Tab…`, rows `Rename to “<typed>”`, `Clear name — back to “<fallback>”`, `Keep “<name>”`; footer `⌘R rename` on a Running row.
- Tab menu copy: `Rename Tab…`, `Clear Name`; tooltip `<name> — <page title>`; mark identifier `browser.tab.<id>.customMark`.
- Journal line `conversation_named`, params `{"provider","messageChars","replyChars"}`, outcome `ok: <name>` or the error whole.
- Commits: no `Co-Authored-By`, no "Generated with" line. Verify each task with `make app-test` (Swift) or `go test ./internal/wakilcore/... ./cmd/wakil-ctx/...` (Go).

## Review Focus

1. **A name of only spaces or newlines typed in a field or the name step** — expected: a clear, never a blank title. Test in Task 8 (`RenameDraft`) and Task 6 (cleaning).
2. **A model reply landing after the window switched organisation, for a conversation of the old one** — expected: dropped, asked again when that organisation is active. Test in Task 5.
3. **The palette closing right after a successful rename run** — expected: one dispatch, not two. Test in Task 8.
4. **A rename before the first turn, then the first turn** — expected: the name is written under the new lineage root, and the model's name does not override it on screen. Test in Task 6.
5. **A 3c layout, a 3d-i layout or pins file with no `name`** — expected: decodes, `name == nil`. Test in Task 12 and Task 13.
