# The Palette Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace ⌘P/⌘K and the top buttons with one palette plane: ⌘P opens or switches to panes, new panes, resources, projects, sessions and providers; ⌘K runs a curated command catalog with input steps; `>` in ⌘P switches to commands.

**Architecture:** All decisions are pure and tested in WakilKit: `PaletteSearch` (multi-word ranking), `PaletteEntry` (one row), `CommandCatalog` (operator verbs → registry actions), `PaletteModel` (a state machine emitting effects), `PaletteSources` (each group, independently fallible). `WindowModel` turns effects into registry dispatches (origin `ui`). WakilApp gets one `PaletteView` drawn as a plane after `Palette.dc.html`; the sheets and the four top buttons are deleted.

**Tech Stack:** Swift 6, SwiftUI, swift-testing; the existing `ActionRegistry`, `fuzzyScore`, `identifierFold`.

**Spec:** `docs/superpowers/specs/2026-10-09-palette-design.md`

## Global Constraints

- ⌘P opens in open mode, ⌘K in commands mode; a leading `>` in open mode switches to commands; deleting it switches back.
- ⌘P groups, in order, empty ones hidden: Open panes · New pane · Resources (tables, API entries, changed files) · Projects (current organisation only) · Sessions · Providers.
- ⌘K is a curated catalog; focused pane's commands first, then global; unavailable commands are hidden, never disabled; raw registry actions never appear.
- Input steps: `.choice` from existing values (typing filters; no free entry), `.text` only for open values with this window's recents shown above as suggestions.
- Search: space-separated words, every word must match the row's title, subtitle or kind label, any order; aliases `db`/`database`/`table`, `api`, `git`, `term`/`terminal`, `pane`, `project`, `session`, `provider`; title hits > subtitle hits > kind hits; the only special character is a leading `>`.
- No match: one row `No results for '<query>'`; Return does nothing.
- Footer copy, verbatim: `↑↓ move · ⏎ <verb> · esc to dismiss`; verbs `open`, `switch to`, `run`, `choose`.
- Plane geometry: OrgPlane's — `black.opacity(0.86)` slab, corner radius 12, width 520, dimmer `rgba(3,4,8,0.58)`. No sheet, no Cancel button.
- Production choices drawn in §5 red `#e85c5c`.
- Every dispatch goes through `ActionRegistry` with origin `ui`. The agent's tool list does not change.
- ↑/↓ **wrap** at both ends (ruling for spec case 12); reopening the palette always starts at the root with an empty query (ruling for spec case 23 — rule 2 is met inside one open palette, where Esc restores a step's query).
- Accessibility identifiers: `palette.plane`, `palette.query`, `palette.step`, `palette.row.<entry id>` (the existing dot form, kept for continuity; the spec's `palette.row:<id>` is superseded here).
- No `Co-Authored-By` trailer on commits.

## Review Focus

1. **A source that hangs** (a database that never answers `db_list_tables`) — typing and every other group must stay responsive; the hung source shows a loading row, then its error. Pinned in Task 4.
2. **The focused pane closes while ⌘K is open** (agent closes it) — its commands vanish, the selection moves to the row now in its place, nothing runs against a dead pane. Pinned in Task 3.
3. **An organisation or project switch while the palette is open** — results from the old context must not be run; the palette re-reads its sources. Pinned in Task 5.
4. **Return pressed twice quickly** on a command — exactly one dispatch. Pinned in Task 3.
5. **A `>` query in commands mode** (⌘K then typing `>`) — a literal search character, not a mode change. Pinned in Task 3.

```swift
import Foundation

public enum PaletteSearch {
    public static let aliases: [String: Set<String>] = [
        "table": ["db", "database", "table"],
        "database": ["db", "database"],
        "api": ["api"],
        "git": ["git"],
        "terminal": ["term", "terminal"],
        "pane": ["pane"],
        "project": ["project"],
        "session": ["session"],
        "provider": ["provider"],
        "command": ["command"],
    ]

    public static func words(_ query: String) -> [String] {
        query.lowercased().split(whereSeparator: { $0 == " " || $0 == "\t" }).map(String.init)
    }

    /// nil when any word matches nothing. Higher is better.
    public static func score(_ entry: PaletteEntry, words: [String]) -> Int? {
        if words.isEmpty { return 0 }
        let kindWords = aliases[entry.kindLabel] ?? [entry.kindLabel.lowercased()]
        var total = 0
        for w in words {
            let title = wordScore(w, entry.title).map { $0 * 100 }
            let subtitle = wordScore(w, entry.subtitle).map { $0 * 10 }
            let kind: Int? = kindWords.contains(w) ? 1 : nil
            guard let best = [title, subtitle, kind].compactMap({ $0 }).max() else { return nil }
            total += best
        }
        return total
    }

    /// Prefix of a word or of the folded whole beats a subsequence (2d-i).
    static func wordScore(_ word: String, _ text: String) -> Int? {
        let fw = identifierFold(word), ft = identifierFold(text)
        if !fw.isEmpty, ft.hasPrefix(fw) { return 1_000 + fw.count }
        let tokens = text.lowercased().split(whereSeparator: { " _-.·/".contains($0) })
        if !fw.isEmpty, tokens.contains(where: { identifierFold(String($0)).hasPrefix(fw) }) { return 500 + fw.count }
        return fuzzyScore(word, against: text)
    }

    public static func rank(_ entries: [PaletteEntry], query: String) -> [PaletteEntry] {
        let ws = words(query)
        if ws.isEmpty { return entries }
        return entries.enumerated()
            .compactMap { i, e -> (Int, Int, PaletteEntry)? in
                if e.isError {   // visible while its own source matches the search
                    return score(e, words: ws).map { ($0, i, e) } ?? (e.title.lowercased().contains(ws[0]) ? (0, i, e) : nil)
                }
                return score(e, words: ws).map { ($0, i, e) }
            }
            .sorted { ($0.0, -$0.1) > ($1.0, -$1.1) }
            .map(\.2)
    }
}
```

Adjust `wordScore` until every test passes; do not weaken a test.

public enum PaletteMode: Sendable, Equatable { case open, commands }

public struct PaletteStep: Sendable, Equatable {
    public let commandId: String
    public let title: String         // e.g. "Environment" — the placeholder
    public var query: String
    public var choices: [PaletteEntry]   // filled by the caller (sources)
    public let isText: Bool
}

public enum PaletteEffect: Sendable, Equatable {
    case run(PaletteAction)          // .dispatch / .focusPane / .setProject / …
    case runCommand(commandId: String, value: String)
    case needChoices(commandId: String)   // caller fills step.choices
    case close
}

public struct PaletteModel: Sendable, Equatable {
    public private(set) var mode: PaletteMode
    public private(set) var query: String
    public private(set) var steps: [PaletteStep]
    public private(set) var selection: Int
    public private(set) var error: String?
    public private(set) var inFlight: Set<String>     // entry ids whose run is in flight
    public var rootEntries: [PaletteEntry]            // set by the caller per mode
    public var recents: [String: [String]]            // recentKey → newest first, this window only

    public init(mode: PaletteMode)
    public var results: [PaletteEntry] { get }        // ranked; one "No results" row when empty and query non-empty
    public var placeholder: String { get }
    public var footerVerb: String { get }

    public mutating func type(_ text: String)        // replaces the query
    public mutating func move(_ delta: Int)          // wraps
    public mutating func confirm() -> PaletteEffect?
    public mutating func escape() -> PaletteEffect?  // .close at the root
    public mutating func modeKey(_ mode: PaletteMode)  // ⌘P / ⌘K while open
    public mutating func runFinished(entryId: String, error: String?)
    public mutating func contextChanged(rootEntries: [PaletteEntry])  // keeps selection on the same id
}
